# Python & AI Engineering Fundamentals

A structured, hands-on learning repository covering Python programming, Data Engineering, AI Engineering, RAG, Agentic AI and Production GenAI Architecture.

## 🎯 Objective

The objective of this repository is to develop strong programming fundamentals and practical engineering capabilities required to design, build, deploy and operate enterprise-grade AI applications.

The learning journey combines conceptual understanding, implementation exercises, coding assessments, architecture discussions and interview preparation.

## 📚 Learning Roadmap

The repository is organised into the following learning tracks:

| Track | Focus Areas |
|---|---|
| 01. Python Fundamentals | Python syntax, data structures, control flow, functions, OOP and advanced Python |
| 02. Coding Fluency | Problem-solving patterns, independent coding exercises and interview assessments |
| 03. NumPy & Pandas | Numerical computing, data manipulation and data analysis |
| 04. Data Engineering | Data processing, SQL and Apache Spark fundamentals |
| 05. AI Engineering | Python for AI, FastAPI, Pydantic and asynchronous programming |
| 06. RAG & Agentic AI | Retrieval-Augmented Generation, LangGraph, multi-agent systems and MCP |
| 07. Production GenAI Architecture | System design, scalability, load balancing, deployment, monitoring and reliability |

## 🗓️ Learning Approach

The programme follows a structured eight-week learning plan with parallel learning tracks.

Each topic will cover:

- Conceptual foundations and internal working.
- Syntax, implementation and practical examples.
- Real-world Data Science and AI Engineering use cases.
- Common mistakes and debugging techniques.
- Independent coding exercises.
- Technical and coding interview questions.
- Revision notes and assessments.

## 💻 Coding Practice Philosophy

A major focus of this repository is developing independent coding proficiency.

Practice will emphasise:

- Writing code without autocomplete or AI-generated suggestions.
- Developing syntax recall and problem-solving ability.
- Implementing solutions independently.
- Debugging and understanding errors.
- Completing weekly timed coding assessments.

## 🚀 Capstone Project

The learning journey will progressively contribute to an **Enterprise Energy AI Platform**, bringing together:

- Document ingestion and processing.
- RAG and retrieval evaluation.
- Agentic AI and MCP integrations.
- API development and conversation management.
- Distributed application architecture and load balancing.
- Containerisation and orchestration.
- Monitoring, security and production reliability.

## 🛠️ Tools & Technologies

Python, NumPy, Pandas, SQL, Apache Spark, Jupyter Notebook, VS Code, FastAPI, LangChain, LangGraph, MCP, vector databases, Docker, Kubernetes and cloud AI platforms.

## 📈 Progress

The repository will evolve alongside the learning programme. Notebooks, implementation examples, exercises and assessments will be added progressively.
